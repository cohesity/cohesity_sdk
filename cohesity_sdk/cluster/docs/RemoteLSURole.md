# RemoteLSURole

Specifies the role of the remote LSU in data transfer operations. Must be one of: 'source', 'target', or 'both'.

## Enum

* `SOURCE` (value: `'source'`)

* `TARGET` (value: `'target'`)

* `BOTH` (value: `'both'`)
